# Realm Counter v7

Serien- und Eliminierungslogik:
- Bei 2 Spielern endet die Partie, sobald ein Spieler 0 erreicht.
- Bei 3–4 Spielern scheidet ein Spieler bei 0 nur aus.
- Ausgeschiedene Spieler bleiben sichtbar, können aber keine Punkte mehr ändern.
- Die Partie endet erst, wenn genau ein Spieler mit mehr als 0 Punkten übrig ist.
- Dieser letzte aktive Spieler erhält den Sieg und den Pokal.
- "Neues Spiel" setzt Punkte zurück und führt die Serie fort.
- "×" beendet die Serie, löscht Seriensiege und setzt Punkte zurück.
- Seriensiege stehen oben rechts im jeweiligen Spielerfeld.

Bestehende Funktionen:
- 4 Spieler im 2×2-Raster ohne Scrollen
- Log hinter Button
- ±1 und freie Eingabe mit − / +
- kumulierende 3-Sekunden-Anzeige
- Undo
- Wake Lock
- lokale Speicherung / Offline-PWA
